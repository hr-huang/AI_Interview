# Development archive

This directory contains implementation plans, design specs, and development reports retained for engineering history.

- `plans/`: historical implementation plans.
- `specs/`: historical design/specification documents.
- `reports/`: task and calibration development reports.

These documents are not the primary product documentation. Some historical records may mention command paths that existed at the time they were written; use the root README and `scripts/README.md` for current commands.
